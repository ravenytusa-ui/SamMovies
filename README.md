# SamMovies (YupFlix Clone)

A modern, responsive movie streaming and download website template built with Tailwind CSS.

## Features
- Netflix-inspired dark UI theme
- Hero banner with backdrop and playback/download buttons
- Trending rows with interactive hover effects
- **Direct download action buttons** built into media cards and hero sections
- Fully responsive layout for mobile, tablet, and desktop devices

## Getting Started
Simply upload `index.html` and this `README.md` to your repository via the GitHub web interface, or clone and host via GitHub Pages!
